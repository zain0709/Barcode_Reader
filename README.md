# Barcode_Reader
This script reads a PDF417 barcode from an image, decodes the information, and extracts key details such as personal and driver’s license data.
PDF417 Barcode Decoder
This Python script decodes PDF417 barcodes from images, extracting personal and driver's license data and returning it in a structured format.

Features:
Decode PDF417 barcodes from images.
Extract key information such as:
Personal details: Name, Date of Birth, Gender.
Driver’s License information: License number, Address, Expiry date, etc.
Output the extracted data in a dictionary format.
Installation:
